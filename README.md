# Expert-Guided PINN Framework

## 🧠 О проекте

Expert-Guided PINN — это система для интерактивного прогнозирования эпидемиологических кривых, которая позволяет эпидемиологам корректировать прогнозы с помощью простых текстовых комментариев, без необходимости глубокого понимания математической модели.

![GIU](./Images/figure_gui.png)

## 🎯 Цель

Преодолеть разрыв между качественными экспертными знаниями (выраженными на естественном языке) и формальными математическими моделями. Система автоматически преобразует текстовые комментарии экспертов в модификации модели, делая процесс калибровки прогнозов доступным и динамическим.

## 🔧 Ключевые возможности

📝 **Текстовая обратная связь** — Эксперт пишет комментарий на естественном языке

🧩 **Автоматическая классификация** — BERT-модель определяет класс и подкласс комментария

🤖 **Генерация кода LLM** — Языковая модель преобразует комментарий в модификации

📊 **Динамическая адаптация PINN** — Модель переобучается с учетом экспертной правки

🔄 **Интерактивный цикл** — Эксперт видит результат и может уточнить комментарий

## 🚀 Два подхода к интеграции экспертного знания

В рамках данной работы реализовано **два подхода** для внедрения экспертных комментариев в PINN:

| | Подход 1 | Подход 2 |
|---|:---:|:---:|
| **Что модифицируется** | Функция потерь (Loss function) | Эпидемические параметры (β, γ, μ) |
| **Способ генерации** | LLM генерирует код loss-функции | LLM генерирует новые значения параметров |
| **Интерпретируемость** | Средняя | **Высокая** (эксперт видит β, γ, μ, R₀) |
| **Сложность реализации** | Выше (требуется валидация кода) | Ниже |
| **Документация** | [`README_RU.md`](./README_RU.md) | [`NEW_PINN_LLM_SUR/LLM_epiparam_generator/README.md`](./NEW_PINN_LLM_SUR/LLM_epiparam_generator/README.md) |

### Подход 1: Модификация функции потерь (Loss)

LLM генерирует программный код модифицированной loss-функции PINN на основе текстового комментария эксперта.

**[📖 Подробная документация Подхода 1](./README_RU.md)**

### Подход 2: Модификация эпидемических параметров (β, γ, μ)

LLM анализирует комментарий эксперта и предлагает новые значения эпидемических параметров SIRD-модели. Эксперт видит, как меняются:
- **β** — скорость распространения инфекции
- **γ** — скорость выздоровления
- **μ** — скорость смертности
- **R₀ = β/(γ+μ)** — базовое репродуктивное число

**[📖 Подробная документация Подхода 2](./NEW_PINN_LLM_SUR/LLM_epiparam_generator/README.md)**

## ✅ Ключевые преимущества разработанных подходов

- ✅ **Использование экспертного мнения** — полная интеграция качественных знаний эксперта
- ✅ **Динамическая адаптация** — модель подстраивается под изменяющиеся условия эпидпроцесса
- ✅ **Гибкость** — не требуется предварительная математическая формализация комментария
- ✅ **Интерпретируемость (Подход 2)** — эксперт видит изменения β, γ, μ и R₀
- ✅ **Причинно-следственное понимание** — система улавливает связь между текстовым комментарием и эпидемиологическими параметрами
- ✅ **Отсутствие жёстких шаблонов** — параметры подбираются совместно, исходя из общей динамики модели
